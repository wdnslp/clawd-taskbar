# 🤖 Claude на панели задач (Taskbar Mascot)

Интерактивный пиксельный персонаж Клода, который живёт прямо на вашей панели задач Windows.

## 🚀 Как запустить

- **Быстрый запуск:** Дважды кликните по [`run.bat`](file:///u:/claudePixeltaskbar/run.bat) (запускается в фоновом режиме через `pythonw`, без лишних чёрных окон консоли).
- **Или через терминал:** `python claude_taskbar.py`

---

## 🎮 Управление и возможности

1. **👋 Клик левой кнопкой мыши:**
   - Клод поднимает правую руку вверх (`right-arm-up.png`) и машет!
   - Через короткое время он опускает руку обратно в исходное положение.

2. **🖐️ Перетаскивание (Drag & Drop):**
   - Зажмите левую кнопку мыши на персонаже и перемещайте его в любое место на панели задач или по экрану.
   - Позиция автоматически сохраняется в [`config.json`](file:///u:/claudePixeltaskbar/config.json). При следующем запуске он появится ровно там, где вы его оставили.

3. **🔍 Изменение размера:**
   - **Колёсико мыши:** наведите курсор на Клода и покрутите колёсико мыши вверх/вниз для плавного увеличения или уменьшения размера с сохранением идеального пиксель-арта (Nearest-Neighbor).
   - **Правая кнопка мыши → Меню «Размер»:** выбор предустановленных размеров:
     - *Половина высоты панели* (~24px, 3x) — по умолчанию
     - *Средний* (32px, 4x)
     - *Большой* (40px, 5x)
     - *Высота всей панели* (48px, 6x)
     - *Крупный* (64px, 8x)

4. **⚙️ Контекстное меню (Правая кнопка мыши):**
   - **👋 Поднять руку** — принудительно запустить анимацию взмаха.
   - **📐 Размер** — переключение готовых масштабов.
   - **📍 Сбросить на позицию по умолчанию** — возвращает Клода в зону системного трея (туда, где было отмечено на скриншоте).
   - **✓ Привязать к низу экрана** — удерживает Клода ровно на нижнем краю экрана.
   - **❌ Закрыть** — завершить приложение.
